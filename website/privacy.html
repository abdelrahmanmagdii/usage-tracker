Privacy

UsageBar is a Mac menu bar app I made. There’s no account with me. Your quota, credentials, and file paths don’t go to a UsageBar server — there isn’t one.

What it reads on this Mac

To draw the meters it talks to tools you already installed:

  • Codex CLI over its local app server.
  • Claude Code from Keychain or ~/.claude, then Anthropic’s usage endpoint.
  • Cursor’s local login database, then Cursor’s usage API.
  • OpenCode Go’s auth.json, then OpenCode’s usage API.

Those companies process that traffic under their own policies. I don’t get a copy.

What’s stored here

Preferences, a short quota history (used to notice surprise resets), and a Tibo Watch cache. All of that lives in the app’s container on your Mac.

Network

Provider usage endpoints, plus a public JSON feed of reset announcements on GitHub. That’s it.

Kids

This is a developer tool. It’s not for anyone under 13.
