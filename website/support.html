Install

Two ways in:

  • Direct: download the notarized .dmg from Releases and drag UsageBar to Applications. No release yet? Build from source.
  • Mac App Store: the listing is pending Apple review and should be live very soon.

Settings

The big button in the popover. Hide tools, pin which window each meter follows, compact vs extended, alerts, launch at login. Right-click the menu bar icon for the same.
