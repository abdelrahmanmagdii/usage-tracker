Get UsageBar working

Install

Mac App Store: the listing is in review / not live yet. Until then, download the notarized .dmg from Releases and drag UsageBar to Applications. If a release is not up yet, build from source on GitHub.

A meter is missing

  • Codex: install and sign in with the official codex CLI, then click Refresh.
  • Claude: sign in with the claude CLI (not only the desktop app). Allow Keychain access once.
  • Cursor: sign in through the Cursor app.
  • OpenCode: run /connect and choose OpenCode Go.

Share to X or LinkedIn

Open the popover → Share. Post on X or LinkedIn copies the 16:9 card and opens compose. Paste the image. macOS share sheet is there if the X or LinkedIn apps are installed.

Contact

File a GitHub issue with macOS version, which provider, and whether you installed from the App Store or GitHub: github.com/abdelrahmanmagdii/usage-tracker/issues.
